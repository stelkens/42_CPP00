# C++ Modules

This repository contains the C++ modules from the 42 Common Core. This project introduce the fundamentals of **Object-Oriented Programming (OOP)** and serve as the starting point of my C++ journey.

The exercises are implemented using the **C++98 standard**, focusing on core concepts and the transition from C to C++.

## Exercises

### ex00 — Megaphone

A simple program that converts all given command-line arguments to uppercase and prints them to the standard output.

Example:
`./megaphone "hello world"` → `HELLO WORLD`

### ex01 — PhoneBook

A console-based phonebook application that allows users to manage contacts using three commands:

* **ADD** — Add a new contact with first name, last name, nickname, phone number, and darkest secret.
* **SEARCH** — Display saved contacts in a formatted table and view detailed information about a selected contact.
* **EXIT** — Exit the program and delete all stored contacts.

The project focuses on basic C++ concepts such as classes, objects, input/output handling, and formatted output using `iomanip`.
